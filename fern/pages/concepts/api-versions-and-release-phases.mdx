This page explains how v1 and v2 endpoints appear in the specs and how to tell GA, public preview and private preview functionality apart.

## v1 and v2 APIs

The `latest/` directory holds the latest GA release, and its specs contain both v1 and v2 API endpoints. They also include v1 and v2 events, so one file gives complete API coverage.

The `preview/` directory is the same as `latest/`, with public preview endpoints added.

The `openapi/` directory is a legacy set that contains v1 endpoints only. It is still updated with every release. New projects should use `latest/` instead.

## GA release

GA means generally available. The `latest/` directory is the recommended location for the latest GA release. Use its files to generate SDKs or client libraries for Stripe's API.

The public GA spec, `latest/openapi.spec3.json`, describes 703 operations.

## Public preview

The `preview/` directory holds the latest public preview release. Use it for early access to upcoming API features before they reach GA.

The preview SDK spec, `preview/openapi.spec3.sdk.json`, describes 803 operations. That is more than the GA public spec, which describes 703. The two files are different variants, so the counts are not a like-for-like comparison.

For Stripe's definition of public preview and the other phases, see the product release phases documentation linked from the README.

## Private preview

The repository also contains a private preview SDK spec, `preview/openapi.private_preview.spec3.sdk.json`. It describes 1125 operations, the most of any spec file listed for this page.

SDK specs carry annotations, deprecated endpoints and pre-release features meant for generating Stripe API libraries. Most users should use the public variant instead.

## x-stripeReleasePhase

`x-stripeReleasePhase` is the vendor extension that records the release phase of the functionality it annotates. The sources for this page do not show its allowed values or exactly where it appears in each spec (needs confirmation). For the other vendor extensions, see [Vendor extensions and fixtures](/concepts/vendor-extensions).

## Beta headers (x-stripeBetaHeaders)

The private preview SDK spec is the one that uses beta headers, recorded through `x-stripeBetaHeaders`. The sources for this page do not show the structure of this extension or the header names it lists (needs confirmation).
