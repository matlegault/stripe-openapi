# Docs conventions

Guidance for anyone, human or agent, editing the docs in this folder. Fern Clerk follows it when it keeps these docs in sync with the code.

## Writing style

Address the reader as "you" and speak plainly, in short declarative sentences. Keep the tone confident and businesslike, with no hype, exclamation marks, or emoji. Use precise technical terms where needed, but explain them briefly rather than assuming deep background.
